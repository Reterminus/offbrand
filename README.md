# off-brand-print - A Shadowverse Custom Card Thing

A full-stack application for creating, managing, and displaying Shadowverse custom cards built with MongoDB, Express, React, and Node.js.

## Features

### Card Management
- Create Shadowverse customs with title, cost, description, image, and grelated fields
- Support for all card types: Followers, Spells, and Amulets with their unique properties
- Token card designation for cards generated by other cards
- Stat tracking for attack and defense values (for Follower cards)
- Evolved and unevolved states with separate descriptions and stats
- Card organization by class, rarity, cost, and trait

### Set Management
- Create and manage card sets with custom names and descriptions
- Add/remove cards to sets for organization
- Browse cards by set
- Add notes to cards within sets for design context or future improvements

### Keyword System
- Define game mechanics keywords with custom descriptions
- Include keyword images with position control
- Associate keywords with cards to streamline creation workflow

### Search and Filtering
- Comprehensive search functionality across card names, traits, and descriptions
- Filter cards by class, rarity, creator, and set
- Sort cards by various attributes

### User Interface
- Card display with hover effects to see details
- Grid and list view options
- Responsive design for desktop and mobile viewing
- Interactive card previews that match the game's style

### Deck Builder
- Create custom decks with the created cards
- Visual deck representation
- Mana curve tracking

### Authentication
- Admin authentication system for content management
- Protected routes for admin-only operations
- JWT-based authentication

## Prerequisites

- Node.js (v14 or higher)

- npm or yarn

## Setup and Installation

1. Clone the repository
2. Install server dependencies:
   ```
   cd server
   npm install
   ```
3. Install client dependencies:
   ```
   cd client
   npm install
   ```
4. Create a .env file in server directory with:
   ```
   MONGODB_URI=your_mongodb_connection_string
   JWT_SECRET=your_jwt_secret
   PORT=5000 (optional, defaults to 5000)
   ```
5. Create a .env file in client directory for custom API URL (optional):
   ```
   REACT_APP_API_URL=http://localhost:5000
   ```
6. Start the server:
   ```
   cd server
   npm start
   ```
7. Start the client:
   ```
   cd client
   npm start
   ```
8. Initialize the admin account (first time only):
   - Visit: http://your-domain/api/auth/init-admin
   - Default credentials will be displayed (username: dumpster, password: @bsolutemor@lity)

## API Endpoints

### Authentication
- `POST /api/auth/login` - Login with username and password
- `GET /api/auth/me` - Get current user info
- `POST /api/auth/init-admin` - Initialize admin user (first-time setup)

### Cards
- `GET /api/cards` - Get all cards
- `GET /api/cards/:id` - Get a single card
- `POST /api/cards` - Create a new card (admin only)
- `PATCH /api/cards/:id` - Update a card (admin only)
- `DELETE /api/cards/:id` - Delete a card (admin only)

### Sets
- `GET /api/sets` - Get all sets
- `GET /api/sets/:id` - Get a single set with populated cards
- `POST /api/sets` - Create a new set (admin only)
- `PATCH /api/sets/:id` - Update a set (admin only)
- `DELETE /api/sets/:id` - Delete a set (admin only)
- `PATCH /api/sets/:id/add-card/:cardId` - Add a card to a set (admin only)
- `PATCH /api/sets/:id/remove-card/:cardId` - Remove a card from a set (admin only)

### Keywords
- `GET /api/keywords` - Get all keywords
- `GET /api/keywords/:id` - Get a single keyword
- `POST /api/keywords` - Create a new keyword (admin only)
- `PATCH /api/keywords/:id` - Update a keyword (admin only)
- `DELETE /api/keywords/:id` - Delete a keyword (admin only)

## Available Views

- `/` - Main card gallery with search and filtering
- `/login` - Admin login
- `/sets` - Browse all card sets
- `/sets/:id` - View cards in a specific set
- `/keywords` - Browse all keywords
- `/deck-builder` - Create custom decks with cards

### Admin-Only Views
- `/create` - Create a new card
- `/edit/:id` - Edit an existing card
- `/sets/create` - Create a new set
- `/sets/edit/:id` - Edit an existing set
- `/keywords/create` - Create a new keyword
- `/keywords/edit/:id` - Edit an existing keyword

### Backend
- Express.js for API server

### Deployment
- The application is configured for deployment on Render.com
- MongoDB Atlas for database hosting

## Card Data Structure

Cards in this application have the following structure:
- **Basic Info**: title, cardType (Follower/Spell/Amulet), cost, rarity, class
- **Follower Cards**: trait, attack/defense stats for both evolved/unevolved states
- **Descriptions**: Based on card type (unevolvedDescription, evolvedDescription, spellDescription, amuletDescription)
- **Metadata**: creator, notes, creation date
- **Relationships**: keywords (references to Keyword documents)

## Usage Notes

- All card images are stored in the `/uploads` directory on the server
- The admin interface is protected by authentication
- Non-admin users can view all content but cannot make changes
- Card images should ideally be high-resolution artwork that fits the Shadowverse aesthetic
